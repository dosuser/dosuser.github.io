PRIVACY POLICY

개인정보 처리방침

DirectionNote 확장 프로그램과 수집 서버가 어떤 정보를 처리하고, 어디에 저장하는지 안내합니다.

최종 갱신: 2026년 11월 1일 · 개발자: dosuser · 문의: dosuser@naver.com

노트는 사용자가 지정한 곳에 저장됩니다. 개인 컴퓨터의 서버, 팀 서버 또는 직접 연결한 클라우드 폴더를 사용합니다. 개발자가 운영하는 별도의 수집 서버로 노트를 보내거나 데이터를 판매하지 않습니다.

노트와 스크린샷에는 페이지에 표시된 개인정보가 포함될 수 있습니다. 저장할 화면과 연결할 서버·폴더를 선택할 때 이 점을 확인해 주세요.

1. 수집하는 정보와 목적

수정 요청을 기록하고, 대상 화면과 요소를 다시 찾으며, 코딩 에이전트 및 팀원과 노트를 공유하는 기능을 제공하기 위해 다음 정보를 처리합니다.

항목내용 및 처리 시점
페이지 정보노트 저장 시 페이지 주소·제목·헤딩·활성 메뉴·화면 크기·브라우저 정보 등 화면을 재현하는 데 필요한 맥락을 기록합니다. 기존 노트 조회를 위해 현재 사이트 주소와 경로도 사용합니다.
선택 요소 정보노트 저장 시 요소의 태그·속성·스타일·텍스트 일부·HTML 일부·위치·상위 요소와 여러 종류의 위치 식별 정보를 기록합니다.
스크린샷과 그림노트 저장 시 보이는 화면 원본·마커 표시본·요소 캡처를 저장하며, 사용한 경우 손그림과 하이라이트 정보를 함께 기록합니다.
직접 작성한 콘텐츠디렉션 텍스트, 우선순위 및 노트 상태 등 작업에 필요한 정보를 처리합니다.
작성자 정보개인 모드에서는 닉네임을 사용합니다. 로그인 방식의 팀 모드에서는 로그인 제공자가 전달한 이메일·이름·닉네임을 처리할 수 있습니다.
인증 및 연결 정보설정한 서버 주소·시크릿·로그인 토큰, 선택한 클라우드 연결의 OAuth 토큰 또는 WebDAV 사용자명·비밀번호를 저장합니다.
선택 기능 설정에이전트 브리지를 활성화하면 접근을 검증하는 무작위 비밀값을 저장합니다. 화면 표시 설정도 기기에 저장합니다.

브라우저 방문 기록 API와 쿠키 API로 정보를 수집하거나 키 입력을 기록하지 않습니다. 다만 선택한 요소의 속성·HTML과 스크린샷에 페이지의 개인정보나 화면에 보이는 입력 내용이 포함될 수 있습니다.

2. 전송 시점과 저장 위치

  • 노트 저장: 사용자가 저장하거나, 직접 활성화한 에이전트 브리지에서 비밀값 검증을 거쳐 저장을 요청할 때 전송합니다.
  • 기존 노트 조회: 배지와 노트를 표시하기 위해 페이지를 열거나 이동할 때, 그리고 주기적으로 노트를 조회합니다. 수집 서버 연결에는 현재 사이트 주소(origin)와 경로(path)를 보냅니다. 클라우드 연결은 노트 파일을 읽어 해당 페이지의 노트를 찾습니다.
  • 개인 컴퓨터의 서버: 기본적으로 ~/.directionnote/ 아래의 노트 데이터베이스와 스냅샷 폴더에 저장합니다.
  • 팀 서버: 사용자가 연결한 서버 관리자의 인프라와 보관 정책에 따라 저장합니다.
  • 선택한 클라우드 폴더: 직접 연결한 Google Drive·Dropbox·WebDAV 폴더에 저장합니다.
  • 확장 프로그램의 로컬 저장소: 연결 정보·인증 정보·닉네임·설정을 저장합니다. 연결이 없거나 전송에 실패하면 노트 본문·스크린샷 등 전송 데이터를 임시 대기열에 보관하고 다시 전송합니다. 전송에 성공한 항목은 대기열에서 제거합니다.

개발자는 사용자가 지정한 저장소에 자동으로 접근하지 않습니다. 팀 서버와 공유 폴더에 대한 다른 사람의 접근 범위는 해당 서비스의 설정에 따라 달라집니다.

3. 제3자 서비스와 데이터 이용

처리한 정보는 노트 기록·조회·공유·인증 등 기능 제공에 사용하며, 광고 판매나 신용 평가를 위해 사용하지 않습니다. 다음 선택 기능은 관련 제공자와 통신합니다.

  • 팀 모드 로그인: 관리자가 설정한 OIDC·LDAP·이메일 로그인 제공자 및 메일 서버.
  • 클라우드 폴더: 사용자가 직접 연결한 Google Drive·Dropbox·WebDAV 운영자. 노트와 스크린샷은 해당 서비스로 직접 전송되며 DirectionNote 개발자 서버를 거치지 않습니다. Google Drive 연결은 drive.file 권한을 요청합니다.
  • 음성 입력: Chrome의 내장 음성 인식 기능을 사용하며 브라우저 및 음성 인식 서비스에서 음성을 처리할 수 있습니다. DirectionNote 확장과 수집 서버는 음성 파일을 직접 녹음·저장하지 않고, 인식된 텍스트를 디렉션 입력에 사용합니다.
  • 에이전트 브리지: 기본적으로 꺼져 있습니다. 로컬 컴퓨터의 localhost·127.0.0.1 페이지에서 활성화 요청을 할 수 있으며, 실제 노트 저장에는 별도의 비밀값 검증이 필요합니다.

4. 보관 및 삭제

노트는 사용자가 삭제하거나 저장소 관리자가 정한 보관 정책에 따라 제거될 때까지 사용자가 선택한 저장소에 보관됩니다. 전송 실패 데이터는 재전송 성공 시 로컬 대기열에서 제거됩니다.

  • 개별 노트는 확장 또는 연결된 서버의 노트 관리 기능으로 정리할 수 있습니다. 완료·제외 상태 변경과 영구 삭제는 다를 수 있습니다.
  • 개인 서버의 전체 데이터는 설정한 데이터 디렉터리에서 관리합니다. 팀 서버의 계정과 데이터 삭제는 서버 관리자에게 요청해 주세요.
  • 클라우드 데이터는 해당 폴더와 서비스에서 관리·삭제할 수 있습니다.
  • 확장을 제거하면 기기의 로컬 설정·인증 정보·미전송 대기열이 제거됩니다. 서버나 클라우드에 이미 저장한 정보까지 자동으로 삭제되지는 않습니다.
  • 로그아웃과 연결 해제는 이미 저장한 노트의 삭제를 의미하지 않습니다. 필요하면 해당 제공자의 계정 설정에서도 접근 권한을 철회해 주세요.

6. 문의 및 변경 안내

개인정보와 제품 사용에 관한 문의는 dosuser@naver.com으로 보내 주세요. 팀 서버나 공유 폴더에 보관된 데이터는 해당 관리자에게도 문의할 수 있습니다.

기능 또는 처리 방식이 바뀌면 이 페이지와 최종 갱신일을 업데이트합니다.

이 안내 사이트는 GitHub Pages와 Cloudflare를 통해 제공됩니다. 호스팅·전송·보안 서비스를 위해 접속 정보가 처리될 수 있으며, 도메인 설정에 따른 Cloudflare Web Analytics 스크립트가 포함됩니다. 이는 확장 프로그램의 노트 저장과 별개입니다. 자세한 내용은 GitHub 개인정보 처리방침과 Cloudflare 개인정보 처리방침을 참고해 주세요. 이 페이지에는 정보를 제출하는 입력 폼이 없습니다.

English summary

DirectionNote records UI change requests, page context, selected element information, screenshots and optional drawings for use by a coding agent. It sends notes to a server or cloud storage connection you configure, not to a collection server operated by the developer. The extension also looks up existing notes automatically; server requests include the current page origin and path.

Local extension storage holds settings and credentials. Failed deliveries, including notes and screenshots, remain in a local queue until successfully sent. Screenshots and element data may contain personal information visible on the page. Optional login, cloud storage and Chrome speech recognition features communicate with their respective providers. DirectionNote does not sell user data or directly record or store voice audio.

You control retention through your server or cloud storage. Uninstalling the extension removes its local data but does not delete already uploaded notes. Contact: dosuser@naver.com.
